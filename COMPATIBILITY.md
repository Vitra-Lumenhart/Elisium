# Elisium and the Webspace family

Elisium is an evolved cousin of `webspace_v6_1_2_fixed` rather than a fork.

| Concept | Chuzhoy webspace v0.6.1.2 | Elisium v0.1 |
|---|---|---|
| Rendering | Bespoke WebGL2 material system | New bespoke WebGL2 world program, ghost material and atlas sprite shader; Canvas fallback in restricted previews |
| Travel | Discrete viewpoint links, fast transitions | Weighted topological graph, locked-duration traversal, concurrently spent fictional time |
| Spatial map | Cartesian X/Z with authored node layout | Cartesian world coordinates decoupled from weighted or future non-Euclidean graph topology |
| Portals | Cross-world portal federation protocol | Single exit-only local portal, closes world, no external handoff |
| Screens | Standalone screen kit with optional iframe | One native HTML world-projected memorial screen, Wikipedia links, no external iframe |
| Trees | Five stylized procedural families | Five new articulated branching families, three frozen growth variants each |
| Flowers / shrubs | Hedges, rose thickets, leaves, shrub ring | Reinterpreted as ghost-gray, translucent, wind-reactive flora |
| Creatures | Not this same two-family atlas technology | Aslan and Tash: one triptych PNG per object, distinct state-selection rules |

## Deliberate boundaries

- The future Webspace portal protocol is **not** activated by this exit. No visit history, identity or coordinates are transmitted.
- The dedication links open Wikipedia using `target="_blank" rel="noopener noreferrer"`; the links are not automatic fetches.
- No network services, authentication, tracking, third-party libraries or licensed character illustrations are needed by the local game.
- The essay's dialogue is an unofficial transformative response to *The Last Battle* and is not presented as original Lewis wording.
- Browser security often prevents a page from closing its own tab if the tab was not script-opened. In that case, the exit **ends the game view** and shows a farewell panel; the user can close the tab manually.
