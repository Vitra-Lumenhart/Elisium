ENGINE REFERENCE · 25 OCTOBER 2026 · REVISION 0.1.0

Elisium

The Names We Give: a graph-native essay-world, an independent Webspace cousin to the Garden of Chuzhoy.

01 · Architectural premise

Elisium renders a single flat Cartesian field while its navigation engine operates on an independent, potentially non-Euclidean graph. Vertices own render-space positions. Edges own time weights and traversal permission. A path is legal only when the edge exists; geographical proximity alone does not imply traversability.

Node:  { id, title, positionXYZ, links[], description, kind }
Edge:  { from, to, independentFactor, costMinutes }
Camera: { posXYZ, yaw, pitch }
State: { current, previous, transit, clockMin, insight, doubt }

cost = max(4, round((distance^0.90 × 2.6 + 3) × edgeFactor))
travelDurationSeconds = clamp(0.80 + sqrt(cost) × 0.23, 1.25, 3.0)

During a crossing, the camera interpolates the Cartesian segment with cubic smoothstep. The fictional clock advances through an independent quadratic easing, consuming exactly the edge's assigned minutes. The next crossing is prohibited until the current one completes. Camera rotation is permitted during travel. Distinct cost factors make graph length and physical length non-identical.

This first revision stores the canonical runtime graph directly in engine.js. world_manifest.json is a synchronized, machine-readable descriptive mirror, not yet runtime-authoritative.

03 · Sprite contract

There are exactly two character sprite families. Each object stores precisely one alpha PNG, packed as three equal horizontal panels of dimension 450×585 pixels each (1350×585 complete atlas). The exact same object is re-rendered as a world-space XY quad, rotated continuously by the camera's right vector, never changing its XYZ position. UV selection is u=(panelIndex+localU)/3. The texture comes from a transparent vector original in assets/*_triptych.svg and make_sprites.py regenerates PNG versions.

Aslan family

Three visual attitudes: attentive radiance, interrogation, compassionate recognition. The active panel depends on a persistent insight counter incremented when the player asks questions in Aslan's dialogue. Thresholds 0, 1, 2+ select panels 0, 1, 2.

Tash family

Three attitudes: distant omen, nearness/attention, self-conscious ambiguity. Panel 1 activates at close physical approach; panel 2 activates once the skeptical doubt counter reaches 2. Proximity and dialogue both matter, unlike Aslan's rule.

Character dialogue is newly written for this experiment. No lines are presented as quotations from Lewis. The reinterpretation foregrounds the original text's conflict: Shift falsely equates the names to consolidate power, while Tirian refuses and Emeth complicates what devotion and judgment mean.

04 · Procedural botanical inheritance

Chuzhoy contributed the family grammar, not copied geometry. Five improved tree generators construct elongated tapered branch trunks, branching crown shapes, and deterministic varieties. All five have three fixed growth stages (sapling = 0.34 scale, juvenile = 0.64, mature = 1.0) selected at scene instantiation, with no in-session age changes.

Secondary foliage includes hedges, roses with bud geometry and alternate leaf shapes, shrub-ring ruins, roots, and ground leaves/ferns. The generator uses seeded pseudo-randomness and excludes its largest structures from nearby traversable links. Thus foliage does not redefine the travel graph.

Ghost tones: one new material system

The shared ghost material forces the input color to grayscale in GLSL. Vertices move in a slow height-proportional oscillation, simulating a shifting spectral outline. Fragment opacity oscillates with time and world position. A view-dependent rim term supplies pearly halos, and distance fog fades the material without turning it opaque. The ghost pass uses alpha blending and disables depth writes. This is intended as a perception-dependent phenomenon, not a physical plant growth animation.

05 · GPU rendering and compatibility

engine.js contains two separate GLSL ES 3.00 programs: a faceted world/ghost program and a billboard sprite-atlas program. Opaque terrain is drawn first, ghost vegetation second, alpha sprites last. The sky occupies a separate 2D canvas under the alpha-enabled WebGL2 canvas. Screen content is a browser-native HTML element projected into world space each frame so real hyperlinks remain accessible and open new tabs.

For embedded webviews without WebGL2, the engine creates a Canvas2D projection that renders low-poly ground bands, reduced species silhouettes, paths, and atlas panels, preserving movement and dialogue. The fallback is intentionally a simpler picture; it does not claim photorealistic or bit-exact parity with the GPU renderer.

06 · Exit and document security

The single portal at Z=18 is behind the initial camera, which faces negative Z. Activation attempts window.close() only in the explicit interaction handler. If tab closure is blocked (the usual browser policy for manually opened pages), an overlay terminates the scene instead. No automatic redirect or graph export occurs.

The memorial screen has exactly two hard-coded outbound links: C. S. Lewis and Inklings. Both open user-activated new tabs with rel="noopener noreferrer".

07 · Reproducible revision discipline

Documentation covenant: Each code revision must update README.md for players (visible behavior, controls, narrative impact) and TECH_MANUAL.html for developers (algorithm, rationale, tradeoffs, validation). The redundant README.txt is retired. These independent viewpoints document the same intent over time.

0.1.1 waypoint culling: The HUD projection now rejects eligible neighbor markers whose ground-plane forward dot product with the camera's facing direction is not greater than 0.5 world units. This supplements existing near-plane, viewport, adjacency, and transit checks. The underlying graph and keyboard travel are unchanged; rotating the camera reveals previously rearward markers.

For every release: copy the current project as the next numeric version; modify engine and images; update this manual's detailed description and tests; run node --check engine.js and node tests/test_manifest.mjs; run python make_sprites.py for authored sprite changes; run python build_preview.py to refresh the single-file preview; finally update README once with player-facing changes.

Current browser validation covered moving between nodes, spending edge cost, reading the Lewis dedication, interacting with Aslan, and switching panels. All four GPU shaders compile under Mesa EGL ES 3.0. The embedded browser used in development blocked native WebGL contexts, so full GPU frame-by-frame visual inspection remains an outstanding manual playtest.
