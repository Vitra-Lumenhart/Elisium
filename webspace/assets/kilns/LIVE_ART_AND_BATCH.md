# The Kilns · Poly Haven live art and one-time batch

Status: an optional in-page 3D **historical model inspector** is implemented on this branch. The Kilns remains an illustrated room graph, not a fully furnished 3D interior.

## Current model on demand, no upload or account

Open [the Kilns world](../../worlds/elisium/kilns/index.html), select a room and object H01–H24, then choose **Load current Poly Haven model**. The client requests Poly Haven's public official /files/{slug} API at click time, chooses the currently available 1k glTF model and follows its declared geometry and texture dependencies via the GLTFLoader. This is a live reference to the latest Poly Haven file metadata at every request, with a visible Powered by Poly Haven credit. A fresh upstream asset may change without a Webspace commit, and dependency availability/CORS are not guaranteed indefinitely.

**Use Webspace proxy** displays the locally served, original low-poly GLB, without contacting Poly Haven. Remote high-fidelity model display requires internet, CDN-hosted Three.js and WebGL. The game's story and session journal still function without the remote model. Opening art never publishes journal data.

These are twenty unique human-created, CC0 **component donors** for twenty-four Kilns object roles. They are not twenty-four finished fantasy game objects. Their geometry is shown in a separate interactive study panel and is **not physically installed in the house**.

## Reproducible one-time archive

The GitHub workflow [Kilns Poly Haven CC0 batch snapshot](../../.github/workflows/kilns-polyhaven-package.yml) runs tools/package_polyhaven_batch.py, obtaining all 20 artist-source 1k glTF sets, their bin files and textures. It checks Poly Haven's MD5 and file size for every component. The archive is called Kilns_PolyHaven_1k_20sources_24objects.zip and includes MANIFEST.json with Poly Haven authors, file hashes, original URLs and H01–H24 mapping.

The archive is published as an Actions artifact on the draft branch, and after acceptance into main, the workflow is configured to create a durable one-time GitHub Release. The archive is a fixed snapshot; the in-game inspector is deliberately live and can request a newer version. **No upload is required from Jepetto** to complete this original Poly Haven donor set.

Source rights: Poly Haven assets are CC0. The game scripts and independent artistic materials have separate rights. The live API requires a visible credit and an identifiable Referer/User-Agent, which this integration supplies in the browser or acquisition script.

## Evidence and limitations

- All 20 distinct model slugs currently advertise 1k glTF with required dependencies and permissive browser CORS.
- GitHub-run Chromium loaded H07's artist model and the Webspace proxy, and confirmed that opening artwork did not create a journal observation.
- The one-time 20-model 1k archive was generated by the GitHub runner with 24 mapping entries, verifying all included hashes; archive size is approximately 42 MB.
- Not yet tested: full 20-model visual survey across hardware; spatial mounting in a 3D Victorian house; native Chuzhoy WebGL2 material handling; durable CDN/library availability. These belong to future work rather than being represented as completed.
