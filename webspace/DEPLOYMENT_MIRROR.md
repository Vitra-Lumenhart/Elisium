# Webspace static public mirror

This folder is rendered under the existing public GitHub Pages site
https://vitra-lumenhart.github.io/Elisium/webspace/index.html .
Its source is the independent canonical public repository:
https://github.com/Vitra-Lumenhart/Webspace/tree/main

Do not develop a second copy of the game inside this mirror. Changes
must be authored and documented in Webspace and intentionally
synchronized after review. The source SHA and exact world entry
mapping reside in ORIGIN.json. The older standalone Elisium root
game and its Pages home page remain separate and unchanged.

The primary gameplay menu contains Chuzhoy, Gerudo Fortress,
Gringotts, Witch's Hole, Elisium and the reserved Purgatorio
placeholder, plus the Kilns nested inside Elisium.
